# Тихий берег

Учебный сайт бронирования восьми лесных домиков у озера. Создан для практики 5 на HTML, CSS и ванильном JavaScript с ES-модулями.

## Что умеет сайт

Схема и карточки строятся из общего массива в `data.js`. На карте также есть точки озера, бассейна, ресепшена, костровой и кинотеатра: нажатие открывает фотокарточку. Можно фильтровать дома по вместимости и максимальной цене, выбирать свободный дом на карте или в списке, указать гостей и число ночей (1–30), увидеть сумму и подтвердить учебную бронь. Брони сохраняются в `localStorage`, восстанавливаются после обновления, отменяются по одной или сбрасываются целиком. Два исходно занятых дома всегда недоступны. Повреждённые данные и запрет на сохранение показывают понятное сообщение.

Бронирование учебное: реальная бронь, регистрация и оплата не оформляются. Дом считается занятым целиком до отмены; даты заезда и выезда не вводятся.

## Изображения и нейросеть

Главные фотографии, по две фотографии первых шести домов, фото бассейна, ресепшена и костровой, а также два фото озера предоставлены пользователем для учебного макета. Седьмой и восьмой дом пока используют прежние изображения; часть из них создана с помощью OpenAI imagegen. Иллюстрированная схема территории нарисована в SVG. Код и тексты созданы с помощью Codex.

Для полной галереи ещё нужны по два снимка домов «Роса» и «Листва». Желательно выбирать фотографии без надписей и водяных знаков и с возможностью использования в публичном учебном проекте.

Полезные запросы к нейросети: «Сделай 8 домов с уникальными id и общей занятостью для схемы и списка» → единые данные в `data.js`; «Проверь числа гостей и ночей и считай цену за ночь × ночи» → проверка и расчёт в `main.js`; «Восстанови брони из localStorage и обработай повреждённый JSON» → модуль `storage.js`.
